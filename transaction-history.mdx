# Transaction History

**`GET /merchant/api/v1/transactions?page=1&limit=20`**

Returns paginated ledger transactions for your merchant wallet.

**Response:**
```json
{
  "success": true,
  "merchant_id": "a1b2c3d4-...",
  "transactions": [
    {
      "id": "ltx_xxxx",
      "type": "payment",
      "amount": 29.99,
      "currency": "USD",
      "direction": "credit",
      "reference": "ORDER-1042",
      "created_at": "2025-01-01T12:31:55Z"
    }
  ],
  "page": 1,
  "limit": 20,
  "total": 142,
  "total_pages": 8
}
```
