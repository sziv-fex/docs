## Response Format

```json
{
  "success": false,
  "error": "message"
}
```

---

## Common Errors

| Code | Meaning |
| --- | --- |
| 400 | Bad request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not found |
| 409 | Conflict |
| 422 | Validation error |
| 500 | Server error |

---

## 🔁 Retry Strategy

Retry only on:

- 500 errors

Use exponential backoff
