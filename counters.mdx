# POS Counters (Terminals)

Each POS terminal must be registered.

## Create Counter

```
POST /merchant/api/v1/counters
```

```json
{
  "name": "Till 1",
  "location": "Main entrance"
}
```

---

## Response

```json
{
  "id": "ctr_xxxx",
  "webhook_secret": "whsec_xxxx"
}
```

---

## ⚠️ Important

* Store `webhook_secret` securely
* Used for webhook verification 

---

## Available Actions

* Create
* List
* Update
* Delete
* Rotate secret
