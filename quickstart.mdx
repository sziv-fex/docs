# Get Started with Fex Payments

Welcome! This guide will help you accept your first payment using Fex in just a few minutes.

## 🧭 Overview

Fex Payments is an alternative payment method (APM) that enables merchants to accept payments directly from customer wallets—without relying on cards.

You can integrate Fex across:

- POS (in-store)
- Web checkout
- Mobile apps

---

## ⚡ Quick Start (5 Steps)

### 1. Create a Payment

Send a payment request from your backend to Fex.

This includes:

- Amount
- Currency
- Transaction details
- Optional callback URL

👉 Fex returns a **payment\_id**

---

### 2. Choose a Payment Flow

Select one of the supported flows:

- QR Code (recommended)
- Phone Number
- Web Button
- Mobile Deep Link

---

### 3. Present Payment to Customer

Depending on the flow:

- Display a QR code
- Collect phone number
- Redirect to Fex
- Trigger mobile deep link

---

### 4. Customer Confirms Payment

The customer:

- Reviews payment in Fex app
- Confirms using biometrics or PIN

---

### 5. Receive Confirmation (Webhook)

Fex sends a **callback/webhook** to your backend when payment is completed.

---

## ✅ Your First Integration (Recommended)

Start with:

👉 **QR Code – Merchant Initiated (Dynamic)**

This is:

- Most scalable
- Best UX
- Used in POS \+ Web
