# Transaction History

## Get Transactions

```
GET /merchant/api/v1/transactions
```

---

## Example Response

```json
{
  "transactions": [
    {
      "id": "ltx_xxxx",
      "type": "payment",
      "amount": 29.99
    }
  ]
}
```
